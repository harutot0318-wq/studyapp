資格勉強向け学習管理アプリ 要件定義書

作成日：2026年7月23日

1. 概要・目的

資格取得を目指す学習者が、学習計画・学習記録・教材管理・復習を一元管理し、効率よく継続して学習できる環境を提供するWebアプリケーション。 日々の学習の「記録のしにくさ」「教材や復習の管理の煩雑さ」「モチベーション維持の難しさ」を解消し、試験本番までの学習を可視化・習慣化することを目指す。

2. 前提条件

項目内容
提供形態Webアプリケーション（ブラウザで動作。将来的にスマートフォンからの利用も想定）
想定利用者資格試験の合格を目指す個人学習者（学生・社会人）
利用人数規模個人利用が基本（1アカウント＝1利用者。他者との共有機能は対象外）
対応資格・科目特定の資格に限定せず、利用者が自由に資格・科目・教材を登録できる汎用設計とする。データは「資格 → 科目 → 教材 → 単語」の階層構造を持ち、複数の資格を並行して登録・管理できる

3. 対象ユーザーと主な利用シーン

  • 複数の資格を並行して学習している場合、画面上部で対象資格を切り替えてから作業する
  • 毎日の学習開始時にダッシュボードを開き、当日の目標とタスクを確認する
  • 学習が終わったタイミングで学習時間・内容を記録する
  • 問題演習中にわからない単語が出てきたら、その場で単語帳に登録する
  • 週末などにまとめて学習分析画面を見て、科目・教材ごとの偏りを把握する
  • 復習予定日が来たら通知・一覧から復習を実施し、理解度を更新する

4. 機能要件

本バージョンより、Should項目（4.9〜4.10）もワイヤーフレームの設計対象に含める。Must／Shouldのラベルは要件としての重要度を表すものであり、初期リリースの画面スコープを限定するものではない。

4.1 資格管理・切替 Must

  • 資格の登録・編集・削除（資格名、試験日）
  • 複数資格の並行登録・管理（例：簿記論とTOEICを同時に学習する場合など）
  • 画面上部などでの対象資格の切替（以降の科目・教材・単語帳・学習記録・タスクは、切替中の資格に属するものが対象となる）
  • 試験日までの残り日数の自動表示

4.2 ダッシュボード Must

表示内容は、原則として現在切替中の資格に関するものとする（複数資格を並行登録している場合、資格を切り替えると表示も切り替わる）。

機能内容
今日の学習時間当日に記録された学習時間の合計を表示
今週の学習時間週（月曜〜日曜など）単位の学習時間合計を表示
連続学習日数学習記録が途切れず続いている日数（ストリーク）を表示
今日の目標達成率設定した日次目標に対する実績の達成率（%）を表示
試験までの残り日数現在切替中の資格に登録済みの試験日から逆算した残り日数を表示

4.3 学習記録 Must

  • 学習時間の記録（開始・終了時刻または時間数の入力）
  • 学習内容・メモの記録（自由記述）
  • 使用教材の登録（教材管理機能に登録済みの教材から選択。選択候補は現在切替中の資格に属する教材に限定される）
  • 科目の登録・選択（科目は現在切替中の資格に属するものとして登録される）
  • 学習履歴の一覧閲覧（日付・科目・教材・時間・メモで絞り込み可能）

4.4 タスク管理 Must

  • 今日やることの登録（自由入力によるタスク作成）
  • 完了・未完了のチェック管理
  • 優先度設定（高・中・低など）

4.5 教材管理 Must

  • 教材の登録・編集・削除（現在切替中の資格の配下、科目に紐づけて登録する）
  • 教材種別の設定（参考書／問題集／動画／その他）
  • 教材ごとの学習進捗管理（例：ページ数・章・進捗率）
  • 教材ごとの学習時間の自動集計（学習記録との連携）

4.6 わからなかった単語帳 Must

  • 単語の登録
  • 意味・解説・メモの登録
  • タグ付け（複数タグ可）
  • 教材との関連付け（どの教材で出てきた単語かを紐付け。教材を介して資格・科目にも間接的に紐づく）
  • 理解度管理（例：未理解／うろ覚え／理解済みの3段階など）
  • 解決済み・未解決の管理
  • 表示範囲の切替（既定は現在切替中の資格に属する単語のみを表示。切替により、登録済みの全資格の単語を横断して一覧表示することも可能。単語の新規登録は、切替表示の状態によらず現在切替中の資格に対して行われる）

4.7 単語検索 Must

  • 単語名によるキーワード検索
  • タグによる絞り込み検索
  • 教材による絞り込み検索
  • 科目による絞り込み検索
  • 未解決の単語のみを表示するフィルタ
  • 検索範囲は既定で現在切替中の資格に属する単語とするが、4.6と同様に切替により全資格を横断した検索も可能とする

4.8 復習管理 Must

  • 復習予定日の設定（単語帳・教材単位を想定）
  • 復習状況の管理（未実施／実施済み）
  • 復習実施後の理解度更新

4.9 目標管理 Should

  • 日・週・月単位の学習目標の設定（学習時間など）
  • 目標に対する達成率の表示

4.10 学習分析 Should

  • 科目別の学習時間集計・表示
  • 教材別の学習時間集計・表示
  • 学習時間の推移表示（日次・週次など）
  • 継続学習日数の推移表示

5. 非機能要件

分類内容
ユーザビリティ毎日使うことを前提に、学習記録の入力は数タップ・数クリックで完結できる簡便さを重視する
データ保持学習履歴・単語帳・教材データは利用者ごとに継続的に蓄積され、消失しないこと
可用性学習の妨げにならないよう、通常利用時間帯において安定して動作すること
拡張性今後の追加機能（AI解説、通知、グラフ分析、バッジ機能等）を後付けしやすい構成とする
対応環境PC・スマートフォンいずれのブラウザからも閲覧・操作できることが望ましい（レスポンシブ対応）

6. 今後追加したい機能（将来拡張）

  • AIによる単語解説 Could
  • 復習リマインダー（通知機能） Could
  • グラフによる学習分析の視覚化 Could
  • バッジ・実績機能によるモチベーション向上施策 Could

7. 今後の検討事項

  • ユーザー認証・アカウント管理の方式（メール／SNSログイン等）　→ 決定：メールログイン＋Googleログイン等のSNSログインを初期リリースから実装（技術選定書 3.4 参照）
  • データのエクスポート・バックアップ機能の要否　→ 決定：本リリース（MVP）のスコープには含めない。将来拡張として別途検討
  • 資格・科目・教材・単語のデータ構造、および複数資格への対応方針　→ 決定：「資格 → 科目 → 教材 → 単語」の階層構造とし、資格は利用者が自由に登録する（マスタ選択式は採用しない）。複数資格の並行登録・切替に対応する（4.1 資格管理・切替 参照）
  • 目標達成率・復習予定日などの通知手段（アプリ内通知／メール／プッシュ通知）
  • マルチデバイス利用時のデータ同期方式
