# 資格勉強アプリ（Study Tracker）

資格試験の学習を「記録・教材管理・単語帳・復習・分析」まで一元管理できる、個人開発のWebアプリです。
複数の資格を並行して勉強していても、資格ごとに科目・教材・単語・進捗を切り分けて管理できるように設計しています。

## このアプリについて

資格勉強でよくある「学習記録が続かない」「教材や覚えた単語がバラバラに散らばる」「モチベーションが分かりにくい」という課題を解消するために作りました。
1人の開発者が、要件定義 → 技術選定 → ワイヤーフレーム → データ設計 → 実装、という流れで一つずつ設計判断を積み重ねて作っています（設計ドキュメントは[下記](#設計ドキュメント)にすべて残しています）。

## 主な機能

| 機能 | 概要 |
|---|---|
| 資格管理・切替 | 複数資格を並行登録し、画面上部からいつでも対象資格を切替。以降の科目・教材・単語・記録はすべて切替中の資格に紐づく |
| ダッシュボード | 今日/今週の学習時間、連続学習日数、目標達成率、試験までの残り日数を集計表示 |
| 学習記録 | 科目・教材・時間・メモを記録。教材ごとの学習時間は自動集計される |
| タスク管理 | 優先度付きのToDo管理 |
| 教材管理 | 教材の種別・進捗率を登録、進捗バーで可視化 |
| わからなかった単語帳 | タグ付け・理解度管理・教材との紐付け。既定は対象資格の単語のみ表示だが、全資格を横断して表示することも可能 |
| 単語検索 | キーワード・タグ・教材・科目・未解決フィルタで絞り込み |
| 復習管理 | 単語・教材単位で復習予定を作成し、実施すると理解度を更新。次回予定日を入れると自動で次の予定が作られる |
| 目標管理 | 日/週/月単位の学習時間目標と達成率 |
| 学習分析 | 科目別/教材別の学習時間、学習時間の推移、連続学習日数の推移をグラフで表示 |
| ログイン | Googleアカウントでのログインのみ（Supabase Auth） |

## アーキテクチャ・データ設計

- データは「資格(exams) → 科目(subjects) → 教材(materials) → 単語(words)」の階層構造。単語帳のタグは`tags`・`word_tags`による多対多、復習は単語/教材のどちらか一方だけを対象にするDBのCHECK制約で表現しています
- 全テーブルでRow Level Security（RLS）を有効化し、`auth.uid() = user_id` を基本ポリシーとして、他人のデータには一切アクセスできないようDB側で担保しています
- サーバーの状態はほぼ全て React Server Components + Server Actions で完結させ、クライアント側JavaScriptは学習分析のグラフ描画（Recharts）にのみ使用しています

詳細は [データ設計書](資格勉強アプリ_データ設計書_v1.html)（ER図・テーブル定義・RLS方針）を参照してください。

## ローカルでの動かし方

### 1. 必要なもの

- Node.js 18.18以上
- Supabaseアカウント（[supabase.com](https://supabase.com) 無料枠でOK）
- Googleアカウント（Google Cloud ConsoleでOAuthクライアントを作成するため）

### 2. セットアップ

```bash
git clone https://github.com/harutot0318-wq/studyapp.git
cd studyapp/web
npm install
```

1. Supabaseでプロジェクトを作成し、SQL Editorで [supabase/migrations/0001_init_schema.sql](supabase/migrations/0001_init_schema.sql) を実行する
2. Google Cloud ConsoleでOAuthクライアントを作成し、リダイレクトURIに `https://<プロジェクト>.supabase.co/auth/v1/callback` を登録する
3. SupabaseのAuthentication → Providers → GoogleにクライアントID/シークレットを設定する
4. `web/.env.local.example` を `web/.env.local` にコピーし、SupabaseのURL・anon keyと `NEXT_PUBLIC_SITE_URL=http://localhost:3000` を設定する

### 3. 起動

```bash
npm run dev
```

または、リポジトリ直下の `start-dev.bat` をダブルクリックすると、開発サーバー起動とブラウザでのアクセスまで自動で行われます（Windows限定）。
